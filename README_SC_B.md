# SC科目B（2027年度以降を想定した非公式オリジナル模試）

## 収録状況

- 制作計画：10回、各12大問／20設問（全120大問／200設問）。
- **このZIPで利用できるのは第1回のみ**：8つの1問1答、4つの1問3答、合計12事例／20設問。
- 制作・査読はオリジナル問題。IPA公式の過去問題・正答ではありません。
- 独立査読で発見された設問013（GitHub Actions）、014（pip）の指摘を局所修正した版を収録。**修正後の独立再査読は未実施**です。
- 詳細は `qa/sc-b/mock01-independent-review.md`、`mock01-review-fix.md` を参照。

## 画面・学習進捗

入口：`sc/b.html`。`assets/sc-b.js` が専用の出題・採点エンジン、`assets/sc-b.css` が既存のダーク＆ゴールドテーマに対する追加スタイルです。

- 1問1答／1問3答は独立した2つのチェックボックス（両方選択可能）。分野フィルターはありません。
- 各設問の`caseId`で共通事例を参照。1問3答の3つの設問は、各々個別に出題・採点・進捗更新します。ランダムでも大問単位に束ねません。
- 事例は各設問で毎回表示し、表・コード・構成図・説明を折りたためます。長い表・コードは枠内で横スクロール可能です。
- 出題数は1/5/10/20/全部。選択肢数は可変（第1回は4〜9択）。
- 正答数、解説、各誤答の理由を表示。生成AIへの相談用テキストのコピーが可能です。
- `localStorage`キーは`ipa-sc-b-progress-v1`。A-1・SC A-2・PD A-2のキーには触れません。
- 進捗：未出題 → 正解でヒット → ダブル → トリプル（3回以上連続正解）。誤答・未回答はミスに戻ります。
- 模試回ボタンを3秒長押しするとその回の進捗だけをリセットします。

## 第2回以降の追加方法

1. `data/sc-b/mock02/` に `cases.json` と `questions.json` を置く（既存の第1回と同じスキーマ、ただしIDは `sc-b-mock02-...`）。
2. `data/sc-b/manifest.json` の `available` 配列に `mock02` を追加し、`expectedCases: 12`、`expectedQuestions: 20` を設定する。
3. `python -m pytest -q` と `node --check assets/sc-b.js` を実行し、ブラウザ上でも実際に1問3答と進捗が正常動作することを確認する。
4. 既存の`cases.json`と`questions.json`のID、正答を勝手に変更しない。学習進捗は設問IDに結び付いています。

直接 `file://` でHTMLを開くのではなく、GitHub Pages等のHTTP(S)配信を使ってください。すべて相対パスです。
