# SC用語記述トレーニング（V5.9 / RC1）

このサイトに新規追加した非公式モジュールです。既存のV5.8サイトを維持して、専門用語200問（第1〜第4回、各50問）を入力式で演習できます。

## 起動と公開

- サイトトップ：`index.html`（SCの3番目のカードから移動）
- 新しい問題画面：`sc/vocab.html`
- GitHub Pages公開先：`https://eikoeigoenglish-star.github.io/rin-ipa-exam/sc/vocab.html`
- ローカル確認：**ZIPの展開ディレクトリのルートで** `python3 -m http.server 8000` を実行し、`http://localhost:8000/sc/vocab.html` を開く。
- `file://` ではJSON読み込みが失敗することがあるため、HTTPで利用してください。

展開したファイル・ディレクトリを**全件**GitHubリポジトリのルートに配置してください。ZIPファイルだけアップロードしても自動展開されません。

## 学習機能

- 第1〜第4回の各50問。初期状態では第1回を選択。複数回選択可。
- 出題状態：未出題 / ミス / ヒット / ダブル / トリプル。
- 難易度：基礎 / 標準 / 高度。出題数：1 / 5 / 10 / 20 / 50 / 対象すべて。
- 出題順：順番 / ランダム。
- 解答は用語を1つ入力してEnterまたは「解答する」。正答候補は問題ごとの acceptedAnswers を使用。
- 自動正解は即座に反映。登録された「関連回答」は**自動正解にはせず**、学習者が「正解として記録 / ミスとして記録」を選びます。
- 不正解・スキップでミス。3回連続正解でトリプル。判定と同時にlocalStorageに保存。
- 回次チップを3秒長押しすると、その回の進捗だけをリセット（確認ダイアログあり）。全件リセットも可能。
- 各設問の解説・参考URL（登録のある問題）を解答後に表示。演習末尾に今回の結果を表示。

### 採点仕様

`NFKC → 小文字化 → 空白・記号・一部不可視文字の除去 → 完全一致`。**「攻撃」の語尾や、版番号（v4.0など）を全問共通で削除する規則は実装していません**。誤って別規格を正解にしないためです。別名は設問単位の許可リストで判定します。

`ipa-sc-vocab-progress-v1` が専用の保存キーです。既存A-1 / SC A-2 / SC B / PD A-2のキーを変更していません。localStorageが無効の場合は永続保存できません。

## データの所在

- `data/sc-vocab/manifest.json`：4回のセット情報。
- `data/sc-vocab/sc-vocab-questions-set01.json`〜`set04.json`：RC1問題200問。
- `data/sc-vocab/sc-vocab-related-answer-policy.json`：関連回答の自己判定候補。
- `qa/sc-vocab/sc-vocab-master.json`：RC1の200語マスター。
- `qa/sc-vocab/sc-vocab-alias-policy.csv`：別名・関連回答の管理表。
- `qa/sc-vocab/validation-summary.json`：修正版のデータ検査結果。

データは作問後の独立査読と、採用済みv2パッチ78行を適用したRC1に基づいています。第1〜4回の順序、用語の割当、questionIdとtermIdは保持しています。

## 保留と限界

- q127「リフレクション攻撃」は関連回答（自己判定）。自動正解ではありません。
- q189「検疫ネットワーク」は関連回答（自己判定）。問題文はNACの総称を求める形に修正済み。
- q196「動的ヒューリスティック法」は参考書の本文の確認待ちで、関連回答の自己判定対象。
- q099 の代表表示名は原本維持。「不正指令電磁的記録作成等罪」は正答別名に登録済み。
- q147 はBOD 26-04について解説を更新。指令URLの追加は保留。
- 参考URLの全件リンクチェックや、改訂された仕様・法令の継続監視は未完了です。
- 実際の本番サイトへのアップロードや公開操作は行っていません。

## テスト

```bash
python3 -m unittest discover -s tests -p 'test_sc_vocab.py' -v
node --check assets/sc-vocab.js
```

この2つは静的・データ検査です。別途、ブラウザの描画環境で、正答別名・関連回答・誤版の負例・結果画面・モバイル表示をスモーク検証しています。ローカルURLを実ブラウザで直接開くことは実行環境の制限があったため、その検証ではHTML・JavaScript・JSONをブラウザに読み込ませました。
