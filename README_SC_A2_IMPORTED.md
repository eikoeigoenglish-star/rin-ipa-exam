## 公開方法

ZIP内 `rin-ipa-exam/` の**中身**を既存の `rin-ipa-exam` リポジトリのルートへ上書き・追加してください。リポジトリの現在の変更を上書きする前に差分を確認してください。GitHub Pages の root 設定を変える必要はありません。

```bash
cd /展開先/rin-ipa-exam
python3 start_local.py
```

`http://localhost:8000/` から `SC 科目A-2` に進むと分母が500問です。直接URLは `/sc/a2.html`。GitHub Pagesの場合は `https://eikoeigoenglish-star.github.io/rin-ipa-exam/sc/a2.html` です。

**画像は提供元の利用条件や外部読み込み制限を確認して利用してください。** 図表や選択肢の欠落は、元ページと照合してから公開版を確定してください。
