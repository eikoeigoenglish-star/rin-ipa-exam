# プロフェッショナル（データ・AI） 科目A-2 / V5.7

## 収録内容

- IPAシラバス案Ver.0.1を参考にした**非公式オリジナル予想問題**230問（模試10回×23問）。IPAの過去問ではありません。
- 8分野を各回2～3問ずつ収録。全分野を複数選択し、なるべく均等に出題します。
- 難易度は制作側の判定で**高度専門相当138問／応用情報相当92問／基本情報相当0問**。公式の出題割合ではありません。
- 別セッションで全230問の独立査読を実施。その後に16問の内容を改修し、50問の難易度表示を査読結果に合わせて修正しました。**最終改修16問の独立再査読は未実施**です。
- 計算・SQL・コード問題の実行検証、正答一意性の自己検証を実施しましたが、全問の専門的正確性・一次資料照合を保証するものではありません。
- シラバス項目数は制作側の読取に基づく62項目。元PDFの該当表を目視確認できていません。

## 既存機能との互換性

- 共通クイズエンジン `assets/app.js` と画面構成を継承。模試選択、分野の複数選択、順番／ランダム、3秒長押し回次リセットを維持。
- A-1（600問）とSC A-2（500問）、両科目の進捗キー・問題JSONは変更しません。
- V5.6のPD-A2草稿から大幅に問題内容が変わったため、PD-A2のみ進捗キーを `ipa-pd-ai-a2-progress-v2` に変更。旧キーは削除せずブラウザに残りますが、新版には引き継ぎません。
- SQLや擬似コードを含む問題文の改行を維持します（PD-A2画面に限る）。
